# ⚖️ PETTY COURT — The Supreme Tribunal of Animal Misdemeanors

> *"Justice is blind. Cats are guilty."*

Petty Court is a premium, cinematic, and entertaining web product where household animals stand trial before distinguished animal magistrates for their most ridiculous domestic crimes — from calculated 3 AM water glass defenestration to grand sourdough larceny.

---

## ✨ Features & Architecture

### 1. 🏛️ Cinematic Courtroom Hero Experience
- **Grand Neoclassical Judicial Design**: Midnight navy backgrounds (`#05070B`, `#0A0F1A`), metallic gold gradients, subtle ambient glows, and the official Petty Court Crest.
- **High Court Live Statistics**: Real-time ticker tracking cases adjudicated, feline conviction rates, canine plea deals, and confiscated treats.
- **Web Audio API Synthesizer**: Realistic, synthesized acoustic wooden gavel strikes and stamp impacts built directly into the browser — zero external audio files or network latency required.
- **Ambient Lighting & Micro-Animations**: Smooth entry reveals, glowing borders, and gold shimmer accents.

### 2. 🐾 The Active Petty Docket (Crime Gallery)
- **Interactive Filtering & Instant Search**: Filter by *Feline Felonies*, *Canine Chaos*, *Avian & Rodents*, or *Citizen Filings*, or search live by suspect name, crime, or docket number.
- **Mugshot Dossiers**: Complete with alias, species, formal indictment, victim statement, and defense alibis.
- **Live Jury Sentiment Voting**: Users can vote *Guilty* or *Innocent*, dynamically updating real-time percentage progress bars persisted in `localStorage`.
- **"Put On Trial" Action**: Instantly loads any suspect directly onto the interactive courtroom bench.

### 3. ⚖️ Interactive Trial Chamber (Live Courtroom Bench)
- **Fictional Presiding Magistrates with Distinct Biases**:
  - **Chief Justice Barnaby Whiskers III**: Senior Cat Jurist (*"Guilty until proven catnip. Dogs have no standing in my court."*)
  - **Magistrate Sir Reginald Barks-a-Lot**: Golden Retriever (*"All charges dismissed if defendant has cheese or is willing to fetch."*)
  - **Hon. Ruth Beaver Ginsburg**: Structural Engineer Jurist (*"Any furniture leg chewed without a permit constitutes high treason."*)
  - **Lady Henrietta Peck**: Night Court Owl Magistrate (*"I see all 3 AM zoomies. Whoooo did it? You did it."*)
- **Evidence Locker Tabs**: Seamlessly switch between Exhibit A (Physical Evidence), Exhibit B (Eyewitness Testimony), and Exhibit C (Priors).
- **Live Court Stenographer Ticker**: Generates real-time, witty courtroom banter as the trial progresses.
- **Tactile Gavel Strike Simulation**: Strikes the sounding block with acoustic resonance, screen rumble, and slams down an authentic rubber stamp (*"GUILTY AS CHARGED"* or *"ACQUITTED ON CHARM"*).
- **Custom Penalties**: Delivers hilarious, tailored domestic punishments.

### 4. 📜 Citizen Indictment ("File a Petit Petition")
- **Intuitive Legal Filing Desk**: Users can report real-world pets by submitting their name, street alias, species, category, crime, victim narrative, and demanded restitution.
- **Preset Mugshot Picker**: Choose from illustrated suspect badges or supply a custom image URL.
- **Live Arrest Warrant Preview**: Updates in real time as the user types into the form.
- **Instant Docketing**: Automatically assigns a unique docket number (e.g. `#PC-2026-4821`), saves immediately to `localStorage`, appends to the active docket, and loads onto the bench.

## 🚀 How to Run the Project

### Option A: Direct Open (Simplest)
Double-click `index.html` or open it in any modern browser (Google Chrome, Microsoft Edge, Brave, Safari, Firefox). No build steps or server required!

### Option B: Local Node.js Server
If you want to serve it locally over HTTP:
```bash
node server.js
```
Then visit: `http://localhost:3000`

## 🛠️ Tech Stack
- **HTML5**: Semantic, accessible markup.
- **CSS3**: Custom design system, CSS variables, glassmorphism, responsive flex/grid layouts, keyframe animations, `@media print` support, reduced-motion accessibility.
- **Vanilla JavaScript (ES6+)**: Zero framework baggage, zero external dependencies, clean component architecture.
- **Web Audio API**: Real-time acoustic sound synthesis.
- **LocalStorage**: Persistent client-side data for votes, user-filed cases, and audio preferences.
- **SVG Vector Assets**: 12 custom courtroom seals, gavels, judges, and suspect portraits ensuring 100% offline fidelity.
